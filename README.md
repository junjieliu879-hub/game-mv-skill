# 像素游戏 MV · Pixel Game MV

**直接运行彩色校园 MV，也可以把完整目录交给 AI 按新歌曲制作。** 包含白蓝校服方块人物、七套原生像素场景、21镜表演、原声预览工作台、48fps导出器与检查工具。无需付费生图/视频接口或其他私人技能。

![彩色校园示例](poster.png)

[查看60秒编码示例](demo.mp4) · [AI制作入口](SKILL.md) · [本例分镜与代码位置](STORYBOARD.md)

画面来自实际校园 MV 制作代码。公开版改用原创示例音乐与英文位图字幕，未上传私人歌曲、歌词、对标视频或系统字体。英文字幕避免首次运行依赖中文字库；中文可用本机字体。

## 开箱运行

需要 **Node.js ≥22、Chrome/Chromium或Edge、FFmpeg及ffprobe**。这些是实际运行依赖；Chrome/Edge自动探测，FFmpeg/ffprobe需在PATH。预览不需要Python；现成背景已带齐。

```sh
npm ci
npm run preview
```

打开提示地址（默认 `http://127.0.0.1:8780`），播放、拖时间轴、开关字幕或静音。首次自动生成原创示例声音，只有本机服务，无需登录或密钥。已附 `demo.mp4` 可直接观看。

另开终端导出同一工程：

```sh
npm run render
```

得到 `output/mv.mp4`：1920×1080、48fps、约60.03秒、H.264/AAC，完整保留音尾。再次运行请换名字，防止覆盖：

```sh
npm run render -- --out output/mv-v2.mp4
```

浏览器找不到时设置 `CHROME_PATH`。渲染临时文件、Chrome profile和缓存只写入项目 `.cache/render/`；可用进程环境变量 `PIXEL_RENDER_ROOT` 改到其他磁盘。端口冲突设置 `PORT`。不修改全局环境，不使用日常浏览器配置。

## 让 AI 制作新歌

把**整个目录**放入客户端的技能目录，或直接给有本地文件、代码与浏览器能力的AI读取 [SKILL.md](SKILL.md)。可以这样下达任务：

> 使用此目录的SKILL.md，按我提供的歌曲、歌词和脚本制作像素MV。先确定人物关系、场面和可见事件；需要我选择时先给实际人物/场景案例。保留原声顺序、速度与音尾。先在正式代表段用完整关键姿态配原声，修清意图、接触、回应和结果，再补过渡与细节。复用画法，按新歌设计动作和镜头。交付编码视频、工作台、唯一分镜与工程；缺少的连续视听如实注明。

本例不是“换音频就自动生成新故事”的模板。`project.js` 管片长、字幕和镜头索引；**`mv.js` 才是完整姿态、走位和场面实现，改变事件和时间时需要同步修改**。只改歌词不会自动改变人物的行为。

实际入口：

| 文件 | 用途 |
| --- | --- |
| `project.js` | 时间、字幕、输出规格、关键状态；本例唯一配置 |
| `mv.js` | 正侧背姿态、步态、视线、伸手、挥别、雨风与场面切换 |
| `assets/campus/*.png` | 七套可直接用的320×180背景 |
| `assets/campus/make-campus.py` | 需要修改背景时重画素材（可选Python+Pillow） |
| `demo.html` / `film.html` | 同一画面引擎的工作台 / 取帧页 |
| `render.mjs` | 本地Chrome按秒取帧，FFmpeg合成指定音轨 |

接入自己的歌：先按原声实际时长修改分镜、`project.js`和对应动作，再在工作台将 `project.audio` 指向自己的文件。将私人素材放入已忽略的 `assets/private/`。导出时明确传同一条原声/混音：

```sh
node render.mjs --page film.html --audio assets/private/song.wav --out output/new-song.mp4 --fps 48
```

局部返修使用 `--start 5.55 --end 12.6`，画面与音频会同时截取同一原曲区间；不要再次偏移已裁好的音频。粗排用 `--blocking true`，无字幕用 `--captions false`。更改声音生成设计后删除生成的 `assets/demo.wav` 再生成；它只属于示例，不替换用户原声。

## 必要检查

```sh
npm run check
node check.mjs output/mv.mp4
```

前者检查镜头时间覆盖、随机跳转确定性、48fps中间采样、全画幅不透明/整数像素、字幕开关和预览播放；后者还检查实际编码规格、音尾及全量解码。结果写入 `output/check.json`。检查不替代正常速度连续听看，不自动判定语义、表演或混音通过。

本包在Windows上完成干净安装、21镜随机跳转与像素检查、预览播放/定位，以及2882帧的1080p48导出与全量解码；21镜抽样画面在关闭字幕后与原校园r3逐像素一致。原声长度60.029388秒，音尾保留。其他系统尚未实机验证，独立全片连续听审未完成。新歌设计与艺术效果仍需实际制作与观看，无需预跑其他风格、无关示例或帧率比较。
